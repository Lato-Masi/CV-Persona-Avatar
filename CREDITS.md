## 🛠️ Key Included Open-Source Technologies & WASM Engines

### 📄 Document Processing & Conversion

* **[@firecrawl/anydoc-wasm](https://github.com/mendableai/firecrawl)**
  * **Original Developers / Maintainers**: Mendable.ai / Firecrawl Team
  * **Description**: High-performance Rust & WebAssembly engine enabling client-side in-browser document conversion across PDF, DOCX, XLSX, ODT, RTF, EPUB, and CSV formats.
  * **License**: Apache 2.0 / MIT

* **[pdf-parse](https://gitlab.com/nico-s/pdf-parse)**
  * **Original Developers / Maintainers**: Nicolas Steiner & Open Source Contributors
  * **Description**: Node.js library for extracting text content from PDF files.
  * **License**: MIT
